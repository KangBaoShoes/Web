Noto Serif SC local Chinese subset
Downloaded: 2026-11-20
File: noto-serif-sc-han-variable.woff2
Style: normal
Variable weight range: 400-600
Subset: 407 unique Han characters extracted from src/App.tsx, src/content.ts and src/catalog.ts
License: SIL Open Font License 1.1
Copyright: 2012 Google Inc. All Rights Reserved.

This font file is an unmodified download generated by the Google Fonts text
subset API. No font binaries were edited locally.
Request base:
https://fonts.googleapis.com/css2?family=Noto+Serif+SC:wght@400..600&display=swap&text=
Append the URL-encoded contents of noto-serif-sc-subset-characters.txt, without
the trailing newline. A modern Chrome user agent selects variable WOFF2.
The exact returned stylesheet and download URL are retained in
noto-serif-sc-subset-source.txt.

Original license source (copy retained as OFL-Noto-Serif-SC.txt):
https://raw.githubusercontent.com/google/fonts/main/ofl/notoserifsc/OFL.txt

The CSS unicode-range includes only the requested Han characters, so this font
does not override the Latin typeface. Characters added to the website later
fall back to local system fonts until this subset is regenerated.
Keep both font license files when redistributing these assets.
